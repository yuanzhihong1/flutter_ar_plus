## 文档维护原则

1. 面向使用者的公开文档统一使用中文。
2. API 名称、类型名和平台专有名词保留原始英文拼写。
3. 代码示例必须可直接复制，并与当前公开 API 保持一致。
4. 行为变化必须同时更新 README、API 文档和 `CHANGELOG.md`。
